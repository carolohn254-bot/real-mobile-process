# Real-Time Mobile Banking — GitHub Pages + Supabase

A responsive academic demonstration of a mobile banking notification system. **No PHP is used** in the customer or administrator application.

## Stack
- HTML5, CSS3 and vanilla JavaScript
- Supabase Auth and PostgreSQL
- Row Level Security (RLS) and a database transaction RPC
- GitHub Pages static hosting

## Files
- `index.html` — sign-in, customer registration, customer and admin views
- `style.css` — responsive layout
- `app.js` — Supabase authentication, data retrieval and user actions
- `config.js` — Supabase project URL and browser publishable key
- `supabase-schema.sql` — tables, signup trigger, RLS and secure transaction function
- `SETUP_GUIDE.md` — complete Supabase setup, admin assignment and GitHub Pages publishing instructions

Start with `SETUP_GUIDE.md`. This is a simulated academic project only; no real funds or bank services are involved.
